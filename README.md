# Box Canoe Buoyancy Calculator
A small interactive browser calculator for the theoretical full-submergence displacement of a rectangular box-shaped canoe.
# Physics
Freshwater density is taken as 62.4 lb/ft³.
Because 1 ft³ = 12³ = 1728 in³:
`62.4 / 1728 = 0.03611 lb/in³` (approximately)
For rectangular dimensions in inches:
`Volume = Length × Width × Depth`
`Maximum buoyant displacement = Volume × 0.03611 lb/in³`
# Run locally
Open `index.html` in any modern browser.
# Important limitation
The result is the theoretical maximum displaced-water weight when the full rectangular volume is submerged. It is not a safe operating payload rating. Real design needs to account for hull/material weight, freeboard, stability, structural limits, occupant distribution, and an appropriate safety margin.
